# QR Code Generator using Python

## 📌 About the Project
This project is a simple QR Code Generator developed using Python. It allows users to generate QR codes from URLs or text input and save them as image files.

## 🚀 Features
- Generate QR codes from text and URLs.
- Convert user input into QR code images.
- Save generated QR codes as image files.
- Simple and easy-to-use implementation.

## 🛠️ Technologies Used
- Python
- qrcode library
- Pillow (PIL)

## 📥 Installation

Install the required Python libraries using:

```bash
pip install qrcode[pil]
```

## ▶️ How to Run

1. Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd QR-Code-Generator
```

3. Run the Python file:

```bash
python qr_generator.py
```

4. Enter the text or URL you want to convert into a QR code.

5. The generated QR code will be saved as an image.
